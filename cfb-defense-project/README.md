# Defense Wins Championships: Defensive Performance and Winning in FBS College Football

This project investigates the relationship between defensive performance and winning in FBS college football.

The analysis uses college football game data to examine defensive measures including points allowed, total yards allowed, rushing yards allowed, and passing yards allowed.

## Research Question

How strongly is defensive performance associated with winning in FBS college football during the NIL era?

## Tools Used

- Python
- Pandas
- Matplotlib
- College Football Data API
- Jupyter Notebook
